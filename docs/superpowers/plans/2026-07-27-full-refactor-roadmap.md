# azpanel 全面重构路线图

本路线图把已批准的全面重构设计拆成可独立运行、评审和回滚的交付阶段。每个阶段开始前基于上一阶段的真实代码状态编写详细实施计划。

| 阶段 | 可验收交付物 | 依赖 |
| --- | --- | --- |
| 1. 兼容基线与认证界面 | 测试基座、功能矩阵、契约快照、设计 Token、浏览器请求层，以及完成迁移的登录/注册/重置页面 | 无 |
| 2. 用户外壳与个人功能 | 响应式用户导航、概览、资料、SSH 密钥、登录记录、分享、回收站、文档 | 阶段 1 |
| 3. Azure 账户与资源组 | Azure 账户 Service 边界、账户/配额/费用/分享/资源组的完整新界面 | 阶段 2 |
| 4. Azure 虚拟机 | 虚拟机 Service 边界，以及创建、状态、规格、磁盘、重装、凭据、防火墙、图表和销毁流程 | 阶段 3 |
| 5. 流量控制与任务 | 规则、日志、任务进度、轮询和失败恢复的新实现 | 阶段 4 |
| 6. 管理后台与其他集成 | 管理员外壳、用户、公告、设置、日志，以及当前可达的通知、代理和其他云能力 | 阶段 2 至 5 |
| 7. Docker 与运维 | 可复现镜像、非 root 运行、健康检查、安装、升级、备份恢复、证书和回滚演练 | 阶段 1 至 6 |
| 8. 清理与最终验收 | 删除无调用方的 MDUI/jQuery/重复模板，完成全量功能矩阵、移动端、升级和回滚验收 | 阶段 1 至 7 |

阶段 1 的详细计划见 `docs/superpowers/plans/2026-07-27-refactor-foundation-auth.md`。
