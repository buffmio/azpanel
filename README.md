## azpanel
演示站点：[https://azpanel.net](https://azpanel.net)

允许注册并正常使用

## 功能
创建 azure 和 aws 虚拟机

## 开发验证

```bash
composer install
composer test
composer analyse
npm run test:js
npm run check:js
```

`composer analyse` 依赖 `phpstan.neon` 中存在有效规则级别或自定义规则；若输出 `No rules detected`，该检查未通过，不能视为静态分析无错误。
